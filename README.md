# Daniel Hinojo website

This is a static website ready for GitHub Pages, Cloudflare Pages, Netlify, or any ordinary web host.

## Files
- `index.html` — the complete one-page multilingual website.
- `styles.css` — visual design and responsive layout.
- `script.js` — ES / EN / DE language switching.
- `legal.html` — placeholder legal notice that should be completed before public launch.
- `images/` — your supplied original photographs.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files in this folder, preserving the `images` folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will give you a public URL.
7. Your existing `danielhinojo.eu` domain can later be pointed to that Pages site.

## Things to review before going live
- Confirm the price and cancellation wording.
- Confirm the public address, telephone number and email address.
- Check that the review quotations and names are exactly as you want them.
- Replace `legal.html` with the legal notice/privacy information appropriate to your activity.
- If you later send the original massage-action photograph, it can easily replace or supplement the current treatment-room background.

No build system or software is required. You can open `index.html` directly in a browser.
